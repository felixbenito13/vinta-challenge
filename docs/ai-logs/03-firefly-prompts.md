# Adobe Firefly · illustration prompts

All prompts written with Claude and run in Adobe Firefly (Gemini 3.1 model), in the order they were iterated. Each was refined after reviewing the output; reasons for each change are in `01-claude-code-session.md` and in board section 13.

Settings: Widescreen 16:9, 1K, approved images used as style references.
